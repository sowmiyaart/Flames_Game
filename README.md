# 🔥 FLAMES Game

A simple and interactive **FLAMES game** built using **HTML, CSS, and JavaScript**.

Enter two names and let the game calculate the relationship result using the classic FLAMES method.

## 🎮 About the Game

FLAMES is a popular name-based game that determines a relationship category from two names.

This project recreates the game as a browser-based application using vanilla **HTML, CSS, and JavaScript**.

## ✨ Features

* 👤 Enter two names
* 🔢 Processes the names to calculate the FLAMES result
* ❤️ Displays the final relationship category
* 🖥️ Simple browser-based interface
* ⚡ Built entirely with vanilla HTML, CSS, and JavaScript

## ❤️ FLAMES Categories

The result is one of the following:

| Letter | Meaning   |
| ------ | --------- |
| **F**  | Friends   |
| **L**  | Lover     |
| **A**  | Affection |
| **M**  | Marriage  |
| **E**  | Enemies   |
| **S**  | Sibling   |

## 🛠️ Technologies Used

* **HTML5** — Structure and input interface
* **CSS3** — Styling and layout
* **JavaScript** — Name processing and FLAMES game logic

## ▶️ How to Play

1. Open the game using the live demo.
2. Enter the first name.
3. Enter the second name.
4. Start the calculation.
5. The game displays the resulting FLAMES category.
